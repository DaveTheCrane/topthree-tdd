# Top Three High Scores

## Requirements
We are running an online gaming site. We wish to reward the top three players with some merch, free playtime, or similar perks. The rewards will run weekly.

The main databases are running under heavy load, so we are asked to compute these scores from an offline CSV file generated by a batch job. The CSV file lists the following:
- player identification (id, online display name)
- title of the game being played (id, display name)
- number of hours played that week
- normalised score across all game-time played that week for the title, in range 1-100

The same player may appear more than once, if they've played different games. Combination of Player id and title should only occur once in the file.

### Sample Rows of Data
`AB1234-7643,BigDaveTheViking,G-134,Plumbers versus dinosaurs in small cars,3,34`

`AB1234-7643,BigDaveTheViking,G-762,Broody cowboys shooting each other,5,71`

Player with id AB1234-7643, known on the site as "BigDaveTheViking", played 3 hours of Plumbers (game id=G134) and got an overall score of 34%, and 5 hours of Cowboys (game id=762), scoring a much better 71%.


## Exercise
Write code that parses the CSV data file, and returns the top three players. We don't need external APIs or a CSV reader. Start wih a List of parsed CSV records as input, and compute a data structure from which we can compute the winners.

Put the code in a local git repository, and commit each step individually, as you build the solution. It's ok just to commit to the main branch.
